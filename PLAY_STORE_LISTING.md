## App name

## Short description
Offline Malayalam Christian songbook for CSI South Kerala Diocese worship and song reference.

## Full description
CSI South Kerala Songbook is an offline Malayalam Christian songbook designed for convenient worship and song reference.

### Features
- 550 songs in the bundled songbook collection
- Worship-order section
- Fast song-number search
- Malayalam text search
- Alphabetical/index browsing
- Favorites
- Recently opened songs
- Previous and next song navigation
- Adjustable reading text size
- Full-screen lyrics reading
- Dark, light, and system theme options
- Share song text when needed
- Works offline after installation

The songbook content in this application is based on the supplied CSI South Kerala Diocese songbook source.
